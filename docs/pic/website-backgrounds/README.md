## Prompt family

使用现有 `hero-atmosphere.webp` 作为风格参考，围绕以下约束分别生成独立构图：

- 科技感与人文温度并存的抽象光场。
- 磨砂玻璃、雾化水彩、矿物颜料和极细纸张颗粒。
- 为标题或产品 UI 保留大面积低干扰区域。
- 浅色版适配深色文字，暗色版适配浅色文字。
- 禁止文字、Logo、人物、设备、UI、卡片、网格和水印。
- 避免霓虹赛博朋克、亮面 3D 球体、银河星空和硬边渐变。

这些文件当前是备用素材，不由页面直接引用。
